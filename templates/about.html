Model Information

Algorithm

Linear Regression

Dataset

Boston Housing Dataset (1970s)

Features

13 numerical features

Target

Median home value (in $1000s)

Important Notes

  • This model is based on historical data from the 1970s Boston area
  • Predictions are estimates and should not be used for actual real estate decisions
  • The model assumes linear relationships between features and house prices
  • All input values must be within the specified ranges for accurate predictions

How to Use

  1. Navigate to the Predict page
  2. Fill in all 13 feature values (or use sample data)
  3. Click Predict Price to get the estimated house value
  4. Review the detailed prediction results
